# 🎬 Sound Design Integration — Expert Video Editing Skill

> Intégrer des effets sonores dans tes vidéos comme un pro : timing, layering, mixing, impact émotionnel

---

## 🎯 OVERVIEW

Le son représente **50% de l'impact** d'une vidéo. Une scène parfaitement filmée tombe à plat sans le bon audio. Cette compétence couvre tout ce qu'il faut savoir pour intégrer le sound design de façon professionnelle.

**Ce que tu vas maîtriser :**
- ⏱️ Timing frame-accurate
- 📚 Layering stratégique
- 🎚️ Mixing et niveaux audio
- 💫 Impact émotionnel
- 📱 Optimisation pour TikTok/Reels

---

## ⏱️ TIMING — La Précision au Frame

### Règle d'Or
> Un son décalé d'**UN SEUL FRAME** peut ruiner l'illusion.

### Où placer les sons
| Moment visuel | Type de son | Placement |
|---------------|-------------|-----------|
| Impact/Collision | Hit, boom | **Exactement** sur le frame de contact |
| Mouvement rapide | Whoosh | Peak audio = point de mouvement max |
| Transition | Swoosh, riser | Début 2-5 frames AVANT, peak sur la coupe |
| Apparition texte | Pop, ding | Sur le frame d'apparition |
| Action en buildup | Riser | Fin du riser = moment clé |

### Technique de Sync Frame-Accurate
1. **Scrubber frame par frame** : Utilise les flèches gauche/droite
2. **Identifier le frame exact** de l'action
3. **Placer le son** pour que son PEAK tombe sur ce frame
4. **Preview** et ajuster si décalage perçu

### Pro Tips Timing
- **Anticipe légèrement** : Le cerveau perçoit le son ~20ms après le visuel, donc placer le son 1 frame avant peut sembler plus naturel
- **Whooshes** : Aligne le pic audio avec le point de mouvement maximum
- **Hits** : Jamais en retard, parfois 1 frame en avance
- **Transitions** : Le son peut commencer AVANT la coupe pour créer de l'anticipation

## 📚 LAYERING — Construire la Profondeur

### Principe
> Ne jamais se reposer sur UN SEUL son. Layerer = réalisme + impact.

### Exemple : Crash de voiture
❌ Un seul effet "car crash"
✅ Layers combinés :
- Pneus qui crissent
- Verre qui explose
- Impact métallique sourd
- Débris qui tombent

### Structure de Layers pour Vidéos Virales

**Layer 1 : BASE (Ambiance)**
- Son d'environnement continu
- Volume bas (-20 à -30 dB)
- Crée le "monde" de la vidéo

**Layer 2 : CORPS (Actions principales)**
- Sons liés aux actions à l'écran
- Volume moyen (-12 à -18 dB)
- Sync précis avec le visuel

**Layer 3 : ACCENT (Impacts & Transitions)**
- Hits, whooshes, risers
- Volume dynamique (-8 à -15 dB)
- Ponctue les moments clés

**Layer 4 : SWEETENER (Polish)**
- Détails subtils (textures, foley léger)
- Volume très bas (-25 à -35 dB)
- Ajoute le "professionnalisme"

### Types de Sons à Layer (TikTok/Reels)

| Élément visuel | Sons à combiner |
|----------------|-----------------|
| **Popup/Apparition** | Digital click + whoosh subtil + sparkle |
| **Transition slide** | Whoosh + impact soft + texture |
| **Texte qui apparaît** | Pop/ding + typing texture |
| **Glow/Highlight** | Chime + shimmer + riser subtil |
| **Zoom rapide** | Whoosh intense + bass drop |
| **Cut rapide** | Impact sec + transition snap |

### Règle des Fréquences
Chaque layer doit occuper sa propre "zone" de fréquences :
- **Basses (20-200Hz)** : Impacts, booms, bass drops
- **Médiums (200-2kHz)** : Voix, actions principales
- **Aigus (2k-20kHz)** : Détails, sparkles, textures

## 🎚️ NIVEAUX AUDIO — Le Mix Parfait

### Références de Niveaux (en dB)

| Élément | Peak Level | Notes |
|---------|------------|-------|
| **Mix global** | -10 à -14 dB | Jamais dépasser -6 dB |
| **Voiceover/Dialogue** | -12 à -15 dB | PRIORITÉ ABSOLUE |
| **Musique (sous voix)** | -18 à -22 dB | Toujours en support |
| **Musique (solo)** | -12 à -16 dB | Quand pas de voix |
| **SFX (impact fort)** | -8 à -12 dB | Pics ponctuels OK |
| **SFX (ambiance)** | -20 à -30 dB | Continu, subtil |
| **Silence relatif** | -40 dB et moins | Pour contraste |

### Hiérarchie du Mix (Ordre de Priorité)
```
1. DIALOGUE/VOICEOVER  →  Toujours audible et clair
2. SFX PRINCIPAUX      →  Supportent l'action
3. MUSIQUE             →  Émotion de fond
4. AMBIANCE            →  Contexte subtil
```

### Technique du Ducking
Quand la voix parle, **baisser automatiquement** la musique/SFX :
- Réduction : -6 à -12 dB pendant la voix
- Attack : rapide (50-100ms)
- Release : lent (200-500ms)

### Éviter le Clipping
- ⚠️ **JAMAIS dans le rouge** (0 dB)
- Viser des peaks à -6 dB max
- Mix final normalisé à -14 LUFS (standard streaming)

## 💫 IMPACT ÉMOTIONNEL — Le Son Raconte

### Comment le Son Crée l'Émotion

| Émotion visée | Techniques sonores |
|---------------|-------------------|
| **Tension** | Drone grave + silence + staccato soudain |
| **Joie/Excitation** | Tempo rapide + aigus brillants + impacts énergiques |
| **Tristesse** | Notes longues + reverb large + silences |
| **Surprise** | Silence → Impact fort → Résonance |
| **Mystère** | Textures étranges + fréquences instables |
| **Puissance** | Bass profonde + braams + layering massif |

### Techniques Narratives

**Le Silence Stratégique**
- 1-2 secondes de silence avant un moment clé = IMPACT x10
- Crée de l'anticipation
- Le contraste amplifie ce qui suit

**Le Buildup**
- Riser qui monte en fréquence ET en volume
- Fin du riser = moment de payoff
- Durée : 2-5 secondes pour Reels

**Le Contrast**
- Passer de calme à intense (ou inverse)
- "Loud-quiet-loud" = engagement
- Varie les dynamiques toutes les 3-5 secondes

**La Répétition**
- Même son/motif qui revient = cohérence
- Crée une signature sonore
- Aide à la mémorisation

## 📱 WORKFLOW CAPCUT — Guide Pratique

### Setup Initial
1. **Importer** vidéo + tous les assets audio
2. **Organiser** : Créer des pistes séparées
   - Piste 1 : Voiceover
   - Piste 2 : Musique
   - Piste 3 : SFX principaux
   - Piste 4 : Ambiance/Foley

### Étapes de Mix dans CapCut

**Étape 1 : Dialogue d'abord**
- Normaliser la voix
- Noise reduction (toggle ON)
- Volume à -12/-15 dB

**Étape 2 : Musique**
- Baisser à -20 dB sous la voix
- Utiliser les fades (in/out)
- Activer ducking si disponible

**Étape 3 : SFX**
- Placer sur les moments clés
- Sync frame par frame
- Ajuster volumes individuellement

**Étape 4 : Polish**
- Preview complet
- Ajuster les transitions audio
- Vérifier sur mobile (test réel)

### Fonctions CapCut Essentielles

| Fonction | Usage |
|----------|-------|
| **Noise reduction** | Nettoyer dialogue |
| **Fade in/out** | Transitions douces |
| **Speed/Pitch** | Ajuster tempo sans changer pitch |
| **Volume keyframes** | Automatisation précise |
| **Audio ducking** | Baisser musique sous voix |
| **Beat sync** | Aligner cuts sur tempo |

## 🔥 RECETTES VIRALES

### Transition Standard TikTok
```
Frame -5 : Riser commence (volume 0 → 80%)
Frame -2 : Whoosh commence
Frame 0  : CUT + Impact peak
Frame +3 : Decay naturel
```

### Hook des 0.5 Premières Secondes
- Son IMMÉDIAT (pas de silence au début)
- Impact ou voix directe
- Basse présente (engage sur mobile)

### Pattern "Satisfying"
```
Action visuelle → Son sync PARFAIT → Micro-silence → Repeat
```
La répétition du pattern crée la satisfaction.

### Build Tension (15-30s)
```
0-5s   : Ambiance calme (-25 dB)
5-12s  : Riser qui monte progressivement
12-14s : Silence (1-2s)
14-15s : DROP/RÉVÉLATION + Impact massif
```

### Storytelling Émotionnel
```
Intro  : Musique douce + voix
Milieu : Tension monte (riser + drums)
Pic    : Silence → Impact
Outro  : Résolution musicale
```

## 🛠️ CHECKLIST PRÉ-EXPORT

### Audio
- [ ] Dialogue audible et clair ?
- [ ] Pas de clipping (peaks < -6 dB) ?
- [ ] Musique ne couvre pas la voix ?
- [ ] SFX sync avec le visuel ?
- [ ] Fades smooth sur les cuts ?
- [ ] Pas de pops/clicks parasites ?

### Impact
- [ ] Le hook audio est immédiat ?
- [ ] Les transitions sont marquées ?
- [ ] Les moments clés ont du punch ?
- [ ] Le silence est utilisé stratégiquement ?

### Test Final
- [ ] Écouter sur téléphone (speaker)
- [ ] Écouter avec écouteurs
- [ ] Volume perçu comparable aux tendances ?

## 📊 MATRICE RAPIDE

| Situation | Solution audio |
|-----------|---------------|
| Vidéo plate, sans énergie | Ajouter impacts sur les cuts + bass |
| Transitions abruptes | Whooshes + crossfade audio |
| Voix pas assez claire | EQ boost 3-6kHz + baisser musique |
| Manque de "pro feel" | Ajouter ambiance subtile + foley |
| Pas assez de punch | Layer les impacts + compression |
| Trop chargé/confus | Réduire layers + créer espace |

---

## 🎓 RÈGLES D'OR

1. **Dialogue > Tout** — Si on n'entend pas la voix, c'est raté
2. **Sync = Crédibilité** — 1 frame de décalage = amateur
3. **Layer ≠ Surcharger** — 3-4 layers max par moment
4. **Le silence EST un son** — L'utiliser pour créer du contraste
5. **Tester sur mobile** — 90% de ton audience écoute sur téléphone
6. **Moins = Plus** — Un mix clean bat un mix chargé
