# rules/couts.md : Savoir avant de dépenser

## Principe
L'équipe n'exige pas le coût zéro : elle exige de savoir avant ce qui sera dépensé, pourquoi, et jusqu'où. Les plafonds vivent dans `doctrine/STUDIO_CONTRACT.json` (`budget`). Un prix mémorisé n'est jamais une autorisation.

## Gratuit sans demander
Lecture, veille avec les sources autorisées, rédaction, gabarits HTML, rendus locaux (ffmpeg, navigateur headless), déclinaisons, transcription si l'outil configuré est inclus dans un abonnement.

## Annoncé dans la carte avant d'être lancé
Génération d'images ou de vidéos par API facturée, voix de synthèse facturée, recherche multi-moteurs payante, tout appel à un service à crédits. La carte porte une ligne : « Coût : ~0,40 € probable, plafond 1,50 € ». Le « Go » vaut pour ce plafond ; un dépassement demande une nouvelle présentation.

## Plafonds par défaut (à ajuster avec David à l'acte 1)
- Par pièce standard : 2 €. Au-delà : présentation dédiée avec devis.
- Par mois, toutes pièces : 60 €. Au-delà : arrêt des productions payantes jusqu'à décision.
- Les crons ne lancent jamais de production payante.

## Trace
Chaque dépense réelle va dans `learning/BUDGET_LEDGER.md` (date, pièce, service, montant, devise). Le rapport mensuel inclut le total.
