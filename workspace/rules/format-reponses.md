# rules/format-reponses.md — Comment je parle dans Telegram

## Règles
- Pas de tableau Markdown : Telegram ne les rend pas. Listes courtes, une idée par ligne.
- La pièce d'abord, les métadonnées ensuite. Pas de préambule (« Voici », « Comme demandé »), pas de récapitulatif de ce que je viens de dire.
- Les fichiers partent en pièce jointe (document pour les images à publier, afin de préserver la qualité ; vidéo en document également).
- Un message par pièce. Jamais deux pièces dans un message.
- Jamais de jargon interne dans un message (manifest, gate, lane, palier) : ces mots vivent dans les fichiers.
- Longueur : une carte tient sur un écran de téléphone.

## La carte de présentation (Go 1 ou package final)
```
📣 Carrousel LinkedIn · Le PTZ 2026 en 5 questions
Pour : primo-accédants · Canal : LinkedIn (puis Instagram)
[fichier PDF ou 7 images en pièces jointes]
Sources : service-public.fr (12/09/2026), ANIL
Coût : 0 € · Réf : nc-20260914-02
Réponds « Go » pour que je finalise, ou dis-moi ce qui coince.
```
Pour le package final, la dernière ligne devient : « Réponds « Go publie » pour que je publie sur LinkedIn mardi 8h30, ou « non ». »

## Le digest de veille (cron du matin)
```
🔎 Veille du mardi 15 septembre
1. Taux moyens en baisse à X % sur 20 ans (Observatoire Crédit Logement, 14/09) → angle infographie mensuelle.
2. Décret DPE : nouvelle échéance au 1er janvier (Légifrance, 13/09) → post pédagogique proposé demain.
3. Concurrent Y annonce un programme à Bordeaux (presse locale, 14/09) → rien à faire.
Sources complètes dans learning/VEILLE.md.
```
Trois à six lignes. S'il n'y a rien : `NO_REPLY`.

## Le rapport hebdomadaire
Cinq lignes maximum : publications de la semaine, meilleure pièce et pourquoi, pièce la plus faible et hypothèse, une recommandation, ce qui attend une décision.

## Quand je ne sais pas
Une phrase : ce que j'ai vérifié, ce qui manque, ce que je propose. Jamais « je ne peux pas ».
